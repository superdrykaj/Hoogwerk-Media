# Overdrachten

Elke overdracht tussen Iris en een specialist staat hier als los bestand, geschreven
door Iris (voor beide richtingen: opdracht én resultaat). Er zijn nog geen taken
gestart, dus deze map bevat nog geen overdrachten.

**Bestandsnaamformaat:** `<TAAK-ID>-<volgnummer>-<van>-naar-<naar>.md`

Voorbeeld: `WEB-0007-01-iris-naar-nova.md`, gevolgd door
`WEB-0007-02-nova-naar-iris.md`, enzovoort.

Verplichte inhoud per overdracht: wie (naam + rol), wat is opgeleverd, de referentie
(versienummer/bestandsreferentie bij een ontwerp of montageplan; exacte Git-commit-
hash bij geïmplementeerde code), en bekende beperkingen. Zie
`samenwerking/BELEID.md` voor de volledige regels.
